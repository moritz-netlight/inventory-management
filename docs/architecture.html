Factory Inventory Management

System architecture, tech stack, and data flow for the demo application.

Overview

A full-stack demo for inventory tracking, order management, demand forecasting, backlog monitoring, and spending analytics across factory warehouses. The frontend is a Vue 3 single-page app that talks to a Python FastAPI backend over HTTP JSON. The backend serves in-memory data loaded from JSON files at startup. There is no database.

System Architecture

The browser loads the Vue app from port 3000. The app calls the API on port 8001 with axios. The API responds with JSON. CORS is enabled on the backend for the frontend origin.

Data Flow

A typical filter change in the UI travels through these steps:

  1. The user changes a filter (time period, warehouse, category, or order status) in FilterBar.vue.Filter state lives in the shared useFilters composable.
  2. The view reacts to the change and calls a method in client/src/api.js.The method builds query params and skips any value set to all.
  3. axios sends GET http://localhost:8001/api/...?warehouse=...&category=....The request crosses origins, so the backend must allow CORS.
  4. FastAPI routes the request to a handler in server/main.py.The handler reads the query params.
  5. The handler filters the in-memory lists. Date filters map quarters to months.Quarter ranges come from QUARTER_MAP. Order dates match on the YYYY-MM prefix.
  6. Pydantic validates and serializes the result against the response model.Any structure mismatch fails here, so keep models in sync with the JSON.
  7. The browser receives JSON. The view stores it in a ref and derives values in computed properties.Charts and KPI tiles are computed from that raw data.

Project Structure

client/

Vue frontend

src/views page components, src/components shared UI and modals, src/composables shared state (filters, auth, i18n), src/api.js the only HTTP layer.

server/

FastAPI backend

main.py routes and filtering, mock_data.py loads JSON at startup, data/ the seed datasets, generate_data.py regenerates them.

tests/

Backend tests

tests/backend/ pytest suites that run the API through FastAPI TestClient.

scripts/ and .claude/

Tooling

scripts/start.sh and stop.sh run both servers. .claude/ holds agent, command, and hook configuration.

Constraints and Conventions

Data

In-memory only

Data is read once at startup. Edits to the JSON files take effect after a backend restart.

Keys

Stable v-for keys

Use IDs such as sku or month, never the array index.

Dates

Validate before parsing

Check dates before calling getMonth(). Inventory filters have no time dimension.

Public repo

No secrets in commits

The repository is public. client/.npmrc pins the public npm registry.
